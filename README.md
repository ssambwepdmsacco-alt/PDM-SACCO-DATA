# SSAMBWE NDEJJE TOWNCOUNCIL - PDM SACCO

PWA deployment package for the Supabase-backed SACCO application.

## GitHub Pages
1. Put these files in the repository root.
2. Enable GitHub Pages for the `main` branch and `/ (root)`, or use the supplied static files directly with a Pages deployment.
3. Open the HTTPS Pages URL.
4. On Android/Chrome or desktop Chrome/Edge, use the browser Install App option. On iPhone/iPad, use Share → Add to Home Screen.

The browser package contains only the Supabase client-side publishable configuration. The Supabase service-role key must never be placed in this repository.
