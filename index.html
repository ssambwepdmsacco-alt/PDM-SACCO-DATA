Import Excel / CSV

Import old members, funded members and applicants into the same master register. Existing records are matched by NIN where available; matched records are updated instead of creating duplicates.

Supported files: XLSX, XLS, XLSM and CSV. The system reads the column headings, matches them to the existing master-register columns, previews the data, and places each value in the correct field. Backup columns: NAME, NIN, GENDER, AGE, AGE GROUP, DISABILITY, MEMBER STATUS, SUB COUNTY, PARISH, VILLAGE, ENTERPRISE, ENTERPRISE GROUP, WENDI A/C NO., AMOUNT, FINANCIAL YEAR, PDM STATUS, PDM AMOUNT, PDM FUNDING DATE, AMOUNT PAID BACK, BIRTH YEAR
